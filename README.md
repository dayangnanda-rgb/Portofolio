# Portofolio Dayang Nanda

Website portofolio statis yang dibuat dengan HTML dan CSS.

## Struktur proyek

```text
portofolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── main.js
└── README.md
```

`index.html` berisi struktur dan konten halaman. `assets/css/style.css` mengatur
tampilan dan responsivitas. `assets/js/main.js` menangani menu navigasi pada layar
kecil.

## Menjalankan

Buka `index.html` di browser. Tidak diperlukan instalasi atau proses build.

## Penyesuaian

Ubah konten, detail profil, dan alamat email di `index.html`. Gaya visual dan
aturan responsif berada di `assets/css/style.css`; interaksi menu berada di
`assets/js/main.js`.
